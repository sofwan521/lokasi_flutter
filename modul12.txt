Uraian
1. Memahami konsep pengambilan lokasi perangkat menggunakan
GPS pada Flutter.
2. Mengakses koordinat latitude dan longitude perangkat secara realtime.
3. Mengubah koordinat menjadi informasi alamat (reverse geocoding)
seperti kelurahan, kecamatan dan kota.
4. Menangani izin (permission) lokasi pada Android.
5. Menampilkan informasi lokasi pada tampilan aplikasi Flutter secara
interaktif dan responsif.
1. GPS (Global Positioning System) adalah sistem navigasi berbasis
satelit yang memungkinkan perangkat untuk menentukan koordinat
geografis (latitude dan longitude).
2. Dalam Flutter, paket geolocator digunakan untuk mengambil lokasi
perangkat, memeriksa status layanan GPS, dan mengelola izin
lokasi.
3. Paket geocoding digunakan untuk melakukan reverse geocoding,
yaitu mengubah koordinat (latitude & longitude) menjadi alamat
yang dapat dibaca manusia, seperti kecamatan, kota, atau negara.
4. Permission Handling sangat penting karena Android meminta izin
eksplisit dari pengguna untuk mengakses lokasi. Terdapat beberapa
status izin: denied, deniedForever, dan granted.
5. Menampilkan data lokasi pada UI memerlukan State Management,
dalam modul ini menggunakan StatefulWidget dengan metode
setState() untuk memperbarui tampilan saat data lokasi diperoleh
atau saat terjadi error.

h. Buat fungsi _getLocation() di dalam kelas _GeolocationScreenState sebelum method build().
Fungsi ini bertugas untuk mengambil koordinat GPS perangkat, memeriksa izin akses lokasi, dan
melakukan reverse geocoding. Hasilnya berupa informasi alamat yang dapat dibaca, seperti
kecamatan/kelurahan dan kota, yang kemudian ditampilkan di layar aplikasi.
Di awal fungsi setState() digunakan untuk memberitahu Flutter bahwa tampilan perlu
diperbarui. Pada tahap ini, aplikasi menandai bahwa sedang memproses lokasi dengan _isLoading
= true dan membersihkan data lama sehingga informasi yang ditampilkan tidak salah atau
tertinggal dari proses sebelumnya. Selanjutnya aplikasi mengecek apakah layanan lokasi atau
GPS aktif menggunakan Geolocator.isLocationServiceEnabled(). Jika layanan tidak aktif
pengguna akan diberi pesan untuk menyalakan GPS terlebih dahulu.
Setelah itu, aplikasi memeriksa izin akses lokasi melalui Geolocator.checkPermission(). Jika
izin belum diberikan, aplikasi akan meminta izin dengan Geolocator.requestPermission(). Izin
lokasi bisa ditolak sementara (denied) atau permanen (deniedForever). Jika ditolak permanen,
pengguna perlu diarahkan untuk mengubah pengaturan aplikasi agar lokasi dapat diakses.
Jika izin diberikan, aplikasi akan mengambil posisi perangkat saat ini menggunakan
Geolocator.getCurrentPosition() yang menghasilkan koordinat latitude dan longitude dengan
presisi tinggi. Koordinat ini kemudian diubah menjadi alamat yang bisa dibaca manusia melalui
fungsi placemarkFromCoordinates(). Hasilnya berupa daftar Placemark dimana aplikasi
mengambil data pertama (placemarks[0]) untuk menampilkan kecamatan (subLocality) dan kota
(subAdministrativeArea).
Selama proses berlangsung, semua kemungkinan error ditangani di blok catch agar aplikasi
tidak crash dan pengguna tetap mendapatkan pesan yang jelas jika terjadi masalah. Terakhir blok
finally memastikan status loading atau spinner berhenti ditampilkan baik proses berhasil maupun
gagal sehingga tampilan aplikasi selalu responsif dan informatif.

Future<void> _getLocation() async {
// 1. Set status loading dan reset data
setState(() {
_isLoading = true;
// Menandai aplikasi sedang memproses lokasi
_errorMessage = null;
// Menghapus pesan error sebelumnya
_kecamatan = null;
// Menghapus data kecamatan sebelumnya
_kota = null;
// Menghapus data kota sebelumnya
});
try {
// 2. Cek apakah layanan lokasi (GPS) aktif
bool serviceEnabled = await Geolocator.isLocationServiceEnabled();
if (!serviceEnabled) {
// Jika GPS tidak aktif, tampilkan pesan error
throw Exception('Layanan lokasi tidak aktif. Mohon aktifkan GPS.');
}
// 3. Periksa izin akses lokasi
LocationPermission permission = await Geolocator.checkPermission();
if (permission == LocationPermission.denied) {
// Jika izin belum diberikan, minta izin kepada pengguna
permission = await Geolocator.requestPermission();
if (permission == LocationPermission.denied) {
throw Exception('Izin lokasi ditolak oleh pengguna.');
}
}
if (permission == LocationPermission.deniedForever) {
// Jika izin ditolak permanen, beri instruksi untuk mengubah pengaturan
throw Exception(
'Izin lokasi ditolak permanen. Anda harus mengubahnya di pengaturan
aplikasi.');
}
// 4. Ambil posisi perangkat saat ini
Position position = await Geolocator.getCurrentPosition(
desiredAccuracy: LocationAccuracy.high); // Presisi tinggi
// 5. Lakukan reverse geocoding untuk mengubah koordinat menjadi alamat
List<Placemark> placemarks =
await placemarkFromCoordinates(position.latitude, position.longitude);
if (placemarks.isNotEmpty) {
// Ambil data lokasi pertama dari hasil reverse geocoding
Placemark place = placemarks[0];
setState(() {
_kecamatan = place.subLocality; // subLocality biasanya kecamatan
_kota = place.subAdministrativeArea; // subAdministrativeArea biasanya
kota

Pada method build() kita membuat tampilan antarmuka menggunakan widget Scaffold
sebagai kerangka dasar halaman. Di bagian atas halaman terdapat AppBar yang menampilkan
judul aplikasi “Lokasi Saya” dengan warna latar biru gelap. Seluruh konten halaman dibungkus
dengan Padding untuk memberi jarak antara tepi layar dan elemen UI agar tampilan lebih rapi.
Di dalam Padding digunakan Column untuk menempatkan widget secara vertikal.
mainAxisAlignment diatur ke center agar semua elemen berada di tengah layar secara vertikal,
sedangkan crossAxisAlignment diatur ke stretch supaya tombol dan kartu informasi melebar
menyesuaikan lebar layar.
Untuk menampilkan informasi lokasi, kita menggunakan widget Card dengan efek elevation
untuk memberi bayangan dan RoundedRectangleBorder agar sudutnya membulat. Di dalam Card
digunakan Container untuk menambahkan padding internal sehingga teks dan indikator tidak
menempel ke tepi kartu.
Bagian konten kartu menyesuaikan kondisi aplikasi menggunakan logika _isLoading,
_errorMessage, dan data lokasi. Jika _isLoading bernilai true maka akan muncul
CircularProgressIndicator di tengah kartu untuk menunjukkan bahwa aplikasi sedang
memproses pengambilan lokasi. Jika terjadi kesalahan, misalnya izin lokasi ditolak,
_errorMessage akan menampilkan pesan error berwarna merah. Apabila lokasi belum diambil
dan tidak ada error, akan muncul teks placeholder yang memberi instruksi kepada pengguna untuk
menekan tombol. Setelah lokasi berhasil didapatkan, kartu menampilkan nama kecamatan dan
kota yang diperoleh dari fungsi reverse geocoding.
Di bawah Card terdapat tombol ElevatedButton yang berfungsi untuk memicu pengambilan
lokasi dengan memanggil metode _getLocation(). Tombol ini secara otomatis dinonaktifkan saat
aplikasi sedang memproses lokasi (_isLoading == true) agar pengguna tidak menekan tombol
berulang kali. Dengan pengaturan ini, UI menjadi interaktif dan responsif, serta memberikan
umpan balik visual yang jelas kepada pengguna sesuai kondisi aplikasi saat ini.

12.3. Kesimpulan
a. Aplikasi Flutter dapat menampilkan lokasi perangkat secara real time dengan memanfaatkan
paket geolocator dan geocoding. Dengan kombinasi ini, koordinat GPS bisa langsung diubah
menjadi informasi alamat seperti kecamatan dan kota.
b. Untuk mengakses lokasi aplikasi harus meminta izin dari pengguna. Penambahan
ACCESS_FINE_LOCATION dan ACCESS_COARSE_LOCATION pada AndroidManifest
memastikan aplikasi bisa mendapatkan akses GPS dengan benar.
c. Widget Scaffold, Card, dan ElevatedButton membantu membuat antarmuka yang rapi dan
interaktif. Tampilan dapat menyesuaikan kondisi aplikasi, misalnya saat memuat data, terjadi
kesalahan, atau data lokasi sudah tersedia.
d. Fungsi _getLocation() menggabungkan pengecekan status layanan lokasi, permintaan izin,
pengambilan posisi, dan reverse geocoding. Dengan cara ini, aplikasi menjadi lebih stabil dan
aman, karena semua kemungkinan error ditangani dengan baik.
e. Dengan setState() aplikasi secara otomatis memperbarui tampilan ketika data berubah. Setiap
perubahan pada _isLoading, _kecamatan, _kota, atau _errorMessage langsung membuat widget
terkait dibangun ulang, sehingga informasi yang ditampilkan selalu terbaru dan sesuai kondisi
saat ini.
